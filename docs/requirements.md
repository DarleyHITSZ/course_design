# 课程设计要求（原始要求摘要）

> 来源：`docs/课设要求.pdf`（9 页，2026 春季学期，机器人学课程设计）。本文件是**要求原文的摘要**，不是评分标准；以 PDF 为准。

## 题目

**书法大咖 —— 六轴机械臂写毛笔字**

## 任务

| 层级 | 要求 | 示例字 |
| --- | --- | --- |
| 简单任务 | 设计合适的末端位姿、轨迹以及运动速度，实现**简单笔画**的书写，并能勾勒出简单的汉字 | 一、八、人 |
| 困难任务 | 按楷书对笔画的要求，运用**提按**等技巧，实现**楷书笔画**的绘制 | 永 |

## 三个难点（评分关注点）

1. **末端位姿**：设计合理的末端位姿，理顺毛笔末端（笔杆姿态与笔尖接触方向）。
2. **轨迹与速度**：设计运动轨迹以及绘制速度，控制笔画**粗细**。
3. **书写技巧**：提按等技巧，提升书写质量（起笔/行笔/收笔的粗细变化）。

## 实现方案（二选一）

1. 毛笔 + 墨水 + 白纸 + 垫子
2. 毛笔 + 自来水 + 仿宣纸

## 硬件参数

- 垫板
- 毛笔、墨水以及纸张
- 夹具（会预先设计好，机械臂末端已夹持毛笔）

## 考核方式

- 最终展示：**5 分钟**汇报 + **现场上机展示**
- 汇报得分与展示得分**各占 50%**，由楼老师统一打分
- 课程设计占课程总分 **20 %**
- **要求至少书写出"工大"二字的轮廓**

## 时间安排

- 期末考试后约两周验收（**11 月 25 日前后**），自觉安排上机测试
- **11 月 17 日前**提交中期报告（一组一份，提交至 1312674370@qq.com），PPT 或 Word，
  简述总体规划、项目进度、遇到的问题；建议此前完成至少一次上机测试

## 本仓库对要求的映射

| 要求 | 实现位置 |
| --- | --- |
| 末端位姿 | `Matlab/BrushConfig.m` 的 `Rtool`（法兰姿态与笔杆倾角）+ `Matlab/WriteTrajectory.m` 的 `tip = flange + L*Rz` |
| 轨迹与速度、粗细 | `Matlab/BrushPlanner.m`（分段梯形规划 + 逐段速度）+ `Matlab/CharLib.m`（笔迹宽度曲线） |
| 提按 | `CharLib.m` 的宽度节点表 → 压入深度 `d = w²/(8R)` → 笔尖 z 高度 |
| "工大"轮廓 | `Matlab/CharLib.m` 的 `工`、`大` 字形；`sim_writing.m` 默认参数 |
| 上机/汇报展示 | `output/writing_joint.txt`（点位文件）、`output/writing_preview.png`（墨迹预览）、`output/writing_path.png`（轨迹图） |
| 中期报告 | 需求见上；本仓库 `README.md` 可作为总体规划素材 |
